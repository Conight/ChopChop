ChopChop 0.0.1-beta.10

This beta brings app and engine updates together, adds engine version selection, and refines feedback throughout the interface.

### Updates and engine versions

- **One Updates settings page:** App update channels, engine versions, and the shared Check for updates at launch option now live in Settings → Updates.
- **Independent checks:** ChopChop and Engine each have their own Check for Updates button. Check All Updates checks both components. Buttons share the same appearance and loading feedback, and individual checks only contact the selected component.
- **Launch checks you control:** Check for updates at launch is enabled by default and checks once per app launch. Turning it off keeps both manual checks available. Checks never install an update automatically.
- **Choose an engine version:** Initial installation and later updates default to Latest, with the five newest compatible stable releases available for manual selection, including switching to an older version. Latest is resolved again before installation; a fixed choice applies to that installation only.
- **Stable update feedback:** Refreshing engine versions keeps the picker in place. Rechecking an available app update keeps its action row in place. The sidebar shows checking activity and returns to the engine's runtime status afterward, without a truncated old-to-new version string or an extra glass capsule.

### Interface refinements

- **Clear action feedback:** Synchronization, applying settings, repairs, bandwidth changes, scheduling, and copy actions show working or successful states without changing button size. Success appears only after the operation succeeds.
- **Smoother transitions:** Download state changes, completion, loading content, empty states, errors, and multi-selection use short, focused transitions. Progress and speed reports do not repeatedly animate the surrounding layout. Reduce Motion is respected.
- **Native queue reordering on macOS 27:** Reorder waiting downloads with native drag feedback. Queue changes use the engine's current order and refresh after an RPC failure. Earlier supported macOS versions keep the existing drag behavior.
- **Refined panels:** Details and command panels use native window transitions, with reliable reopening and input focus.

### Updating and installation

Beta.10 uses the **same update verification key as beta.3 through beta.9**. Users on beta.7 or later can update through ChopChop's updater. Manual installation from the DMG is recommended for older betas because their updater may stall while waiting for the previous app to quit. Quit ChopChop normally before replacing it in Applications.

Existing settings, task history, downloaded files, and engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.10-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layouts, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
