ChopChop 0.0.1-beta.4

This maintenance beta consolidates release configuration and shared Engine, update, and storage rules. Existing settings, task history, downloaded files, and Engine recovery data keep their current locations.

### Improvements

- **One release configuration:** The app, installer service, packaging checks, and signing tools now read the same repository, application identifier, and public verification key. Independent forks can configure their own distribution without editing scattered update URLs.
- **Consistent Engine handling:** Release discovery and downloads share canonical upstream endpoints and asset names. Startup, installation, torrent metadata access, and rollback share the same persistent storage layout.
- **Consistent update recovery:** Installer downloads, cleanup, recovery, and the installation worker share directory names and ownership checks. Temporary update directories must have the expected prefix and a complete UUID.
- **Clearer code ownership:** Download models, draft validation, Tracker sources, ED2K, proxy detection, file removal, and power management now have dedicated modules. Shared build tools and integration-test downloads use one implementation.
- **Contributor documentation:** Added a module ownership guide and instructions for configuring and signing an independent fork.

### Updating

Beta.4 uses the **same update verification key as beta.3**. From beta.3, select a channel that includes pre-releases, check for updates, and use **Install and Restart**. Downloads and BitTorrent seeding remain paused after reopening until you resume them.

Users of beta.1 or beta.2 should install this release manually using the DMG to obtain the signed updater. The app contains only the public verification key; the private signing key stays in the release signing environment.

### Installation and validation

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Apple Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.4-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layout checks, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
