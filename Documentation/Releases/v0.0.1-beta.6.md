ChopChop 0.0.1-beta.6

This beta makes download actions easier to reach while keeping the native list clear and compact.

### Improvements

- **Details and removal in every row:** Open a task's details or remove it directly beside the existing start/pause control. The buttons use native icons with tooltips and accessible names.
- **Predictable removal:** A row's Remove button targets only that task, even when several tasks are selected, and follows your existing confirmation preferences. The selection bar and contextual menu retain their batch actions.
- **Better narrow-window layout:** Transfer speeds and remaining time move beneath progress when space is limited, leaving room for filenames and all three action positions. Completed, failed, offline, and finalizing tasks keep consistent row alignment.
- **Familiar interactions:** Space still opens details, and double-click still pauses or resumes a download. Details remain available while the Engine is offline.

### Updating

Beta.6 uses the **same update verification key as beta.3, beta.4, and beta.5**. Beta.5 users can install it from ChopChop's update window; this release retains beta.5's corrected Install and Restart quit sequence.

**For beta.3 and beta.4, manual installation from the DMG is recommended.** Those versions still run their old quit implementation during an in-app update and may remain at **Waiting for ChopChop to quit**. Quit ChopChop normally before replacing it in Applications. Users of beta.1 or beta.2 should also install manually.

Existing settings, task history, downloaded files, and Engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

### Installation and validation

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.6-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layouts, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
