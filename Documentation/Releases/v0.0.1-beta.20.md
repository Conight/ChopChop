ChopChop 0.0.1-beta.20

This beta fixes HTTPS certificate trust and simplifies Engine settings around ChopChop's automatic engine management.

### Improvements and fixes

- **Native macOS certificate trust:** HTTPS downloads now use macOS's native trust evaluation. This fixes false certificate-chain failures caused by overriding the system trust store with a separate static CA file. Certificate and hostname verification remain enabled. After updating, retry affected downloads; existing tasks and download data do not need to be cleared.
- **Clearer Engine settings:** The Engine page now focuses on status, updates, connection recovery, and advanced configuration. Redundant Start Engine and manual Apply controls have been removed. ChopChop starts and manages the engine automatically; restored downloads still wait for you to resume them.
- **Settings apply automatically:** Supported settings are applied to the running engine after editing, with visible errors and a retry action if application fails. Clearing the proxy, bypass list, or User-Agent now clears the corresponding engine value. Live BitTorrent and ED2K options no longer require unnecessary restarts, and ordinary settings edits preserve scheduled bandwidth limits.
- **Accurate restart and recovery state:** Settings that require a restart identify the affected configuration. Connection failures offer recovery in the appropriate state, and engine-update rollback restores the last accepted connection settings instead of unverified pending changes.

### Engine requirement

**Aria2 Next 3.0.8 or later is required.** The engine remains a separate download from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases). Install or update it through **Settings → Updates**.

Existing download history, files, and engine recovery data are retained. Updating ChopChop does not automatically resume paused downloads.

### Updating and installation

Beta.20 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.20-macos-arm64.dmg.sha256
```

### Validation

The implementation passed full main-branch CI, including Swift and native keyboard/window tests, Chinese layout checks, browser-extension tests, real Aria2 Next 3.0.8 HTTP/BitTorrent and media downloads, signed updater checks, and Release verification.

New local HTTPS regressions verify that macOS-trusted certificates download successfully, the former static CA-file override reproduces the failure, and unknown issuers and mismatched hostnames remain rejected. The disposable fixture also verifies that its temporary certificate trust is revoked after testing.

The release workflow repeats the shared verification gate before packaging, verifies the mounted DMG, and signs the update manifest. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
