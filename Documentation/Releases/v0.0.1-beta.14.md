ChopChop 0.0.1-beta.14

This beta adds a complete About window and easier access to help, project information, and engine licenses.

### About and project information

- **About ChopChop:** Open the native window from the application menu to see the app version, build number, and the installed or running Aria2 Next version. Copy Version Information includes app, engine, and macOS versions for a problem report, without download tasks or file paths.
- **Project links:** Visit the ChopChop and Engine GitHub repositories, read release notes for the installed app version, check for updates, or report a problem directly from About and Help.
- **Keyboard shortcuts:** A separate Help window lists common commands and task-list shortcuts, including selection, paste, removal, and download details. Command names and shortcuts reuse the app's command definitions.
- **Acknowledgments and licenses:** Read contributor credits, engine notices, and the complete GNU GPL license inside the app, including offline. ChopChop's existing copyright and licensing statement is preserved; Aria2 Next retains GPL-2.0-or-later.
- **Help improvements:** The user-guide link now opens the complete guide. Help also groups project links, release notes, diagnostic preview, and acknowledgments. All new interfaces support English and Simplified Chinese.

### Updating and installation

Beta.14 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. The engine is downloaded separately. This release does not change task storage, the engine minimum, or file-removal behavior.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.14-macos-arm64.dmg.sha256
```

### Validation

The shared CI/release gate covers keyboard UI regressions, Swift/migration tests, English/Chinese layout, browser-extension checks, real engine/media downloads, signed updater checks, and Release/DMG verification. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified. About, shortcut, and acknowledgment windows were also inspected in the development app, including offline license expansion.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
