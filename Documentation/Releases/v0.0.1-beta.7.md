ChopChop 0.0.1-beta.7

This beta fixes the long delay between quitting ChopChop and restarting it during an app update.

### Fixes

- **Prompt update installation after quitting:** The installer now listens for the old process to exit instead of waiting for macOS to clear its application registration. This resolves a delay that could leave updates at **Waiting for ChopChop to quit** even after the app had already exited.
- **Reliable handoff:** Exit monitoring starts before the installer tells the app it is ready, so a quick shutdown cannot be missed. Session cleanup still finishes before replacement, and the installer never force-quits the app.
- **Regression coverage for the real update path:** Tests now launch the installer through the app's embedded XPC service, verify normal shutdown, and check that the replacement starts promptly. Signature validation, failed-launch rollback, download error handling, and user-data preservation remain covered.

### Updating

Beta.7 uses the **same update verification key as beta.3 through beta.6**.

**Manual installation from the DMG is recommended when upgrading from an earlier beta.** The currently installed app runs its own updater, so this fix takes effect only after beta.7 is installed. Beta.3 and beta.4 may stall while quitting; beta.5 and beta.6 may keep waiting after the app has exited. Quit ChopChop normally before replacing it in Applications. If an earlier update is already stuck, restart your Mac before installing the DMG. Users of beta.1 and beta.2 should also install manually.

Existing settings, task history, downloaded files, and Engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

### Installation and validation

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Update signatures do not replace Apple Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.7-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layouts, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
