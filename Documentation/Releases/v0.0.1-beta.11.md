ChopChop 0.0.1-beta.11

This beta improves live download updates, makes magnet discovery easier to diagnose, and keeps Tracker settings in sync with running torrents.

### Engine and download reliability

- **Aria2 Next v3 or later is required.** Installation and update selection now show supported v3+ stable releases only. Engine v2 support and obsolete settings have been removed. If you have a v2 engine, install a supported version when prompted before resuming downloads. The engine remains a separate download from its official upstream releases.
- **Independent notifications and commands:** WebSocket receives engine notifications, while operations and queries use HTTP JSON-RPC. Notification connections reconnect automatically; stale requests from a previous engine session cannot update the current one.
- **Responsive, consistent transfer values:** The list and task details use the same task speed sample. Lightweight foreground sampling updates active transfers without repeatedly loading full file lists or rewriting history; background refreshes run less often.
- **Bounded connection retries:** HTTP/SFTP attempts default to three instead of retrying forever at zero bytes. Network settings expose the maximum attempt count, and exhausted attempts show the engine's error. Existing unlimited session options are backed up before being bounded. This does not bypass TLS validation or network routing rules.

### BitTorrent and Trackers

- **Full Tracker lists:** Large lists are retained and passed to the engine without truncation. Startup configuration keeps long lists out of process arguments.
- **Automatic synchronization:** While ChopChop is running, enabled Tracker sources synchronize at the configured interval, including when Settings is closed. Missed work resumes after wake, and failures retain the cached list with retry feedback.
- **Apply to active torrents:** Syncing or applying Tracker settings merges new addresses into running downloads and seeding tasks while retaining existing trackers and tiers. Paused tasks are not resumed to apply an update.
- **Clear magnet discovery status:** The loading sheet shows Tracker responses and errors, peer connection and handshake stages, and engine-wide DHT node counts. After a long wait, it explains the current stage and offers Retry Connection. Missing diagnostics are shown as unavailable rather than zero.
- **Correct file selection and torrent copies:** Metadata placeholders no longer appear as ready zero-byte files. Saving a torrent copy uses the v3 task-based resume location and allows a bounded wait for the engine to save metadata.

### Interface stability

- **Targeted live updates:** Transfer changes update the relevant values without broadcasting unrelated changes through settings, input sheets, navigation and other tasks' details.
- **Stable selection and columns:** Selected-row text keeps its contrast during speed updates. Arrows, numbers, units, transferred sizes and percentages have reserved positions, preventing digit and unit changes from shifting adjacent content.
- **Preserved content and focus:** Network details retain their last snapshot during temporary failures and show its update time. File and peer rows retain their order during live progress changes; sorting or Refresh Order applies a new order. Native controls and Dock progress views are reused.
- **Consistent numeric settings:** Network, BitTorrent and ED2K use editable numeric fields with small native steppers, vertically centered with their setting descriptions.
- **Calmer appearance:** The blue accent is more subdued, and the download workspace's decorative background is restored. System contrast and Reduce Motion settings remain supported.

### Local development

Local Debug and Release builds are now **ChopChop Dev**, with a separate Bundle ID, data container, engine state, ports and permissions. The production package retains the existing ChopChop identity and update key. Local checks use Apple Development signing and a stable test-host path; the Distribution configuration is reserved for packaging.

### Updating and installation

Beta.11 uses the **same update verification key as beta.3 through beta.10**. Users on beta.7 or later can update through ChopChop's updater with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Settings, task history, downloaded files and engine recovery data remain outside the app bundle. Restored downloads and BitTorrent seeding stay paused until you resume them. Engine v2 installations must be replaced with v3+ to use this release.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.11-macos-arm64.dmg.sha256
```

The release gate covers Swift and migration tests, English/Chinese layouts, browser-extension tests, real HTTP/RPC and BitTorrent transfers, WebSocket reconnection, Tracker updates, HLS/DASH downloads, signed updater installation/restart/rollback, and Release/DMG verification. The engine smoke-test baseline is Aria2 Next 3.0.2. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next binaries are obtained separately from [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
