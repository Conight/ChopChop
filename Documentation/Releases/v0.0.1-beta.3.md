ChopChop 0.0.1-beta.3

This beta adds signed in-app updates and improves Settings, download management, and release-note readability.

### What's new

- **Signed in-app updates:** A dedicated update window downloads releases directly from GitHub, shows progress, transfer size and speed, and verifies an Ed25519-signed manifest before installing. Choose stable releases or pre-releases, cancel a download, or hide the window while it continues.
- **Install and restart:** Verified updates can save the download session, quit ChopChop, replace the app, and reopen it. Interrupted preparation can be recovered, and installation failures preserve or restore the previous app. Downloads and BitTorrent seeding remain paused after reopening.
- **Readable release notes:** Headings, lists, emphasis, links, code blocks, and tables now render as native selectable text. Fixed a scroll-range bug that could hide the final paragraphs after resizing the update window. Update progress and footer actions remain visible.
- **Cleaner Settings:** A full-height native sidebar and one persistent search field serve all seven first-level pages. Search opens the relevant setting without extra pages or highlight outlines. Long forms scroll within the window, with Apply Settings available at the bottom where needed.
- **Task commands and batch actions:** Use Command/Shift selection to pause, resume, or remove multiple tasks. Command search (`Shift–Command–P`) provides quick access to common actions. Partial batch failures are reported without discarding successful changes.
- **Files and transfer details:** Native tables support file filtering, sorting, selection, and priority changes. Peer rows remain stable while their values refresh, and detail windows retain their size and selected tab for the current session.
- **Native interaction and efficiency:** Refined toolbar sizing, menu presentation, controls, and Add Download layouts. Row updates avoid republishing unchanged data, background polling is reduced, and detailed telemetry follows the visibility of its window.

### Updating from an earlier beta

Beta.3 is the first published release with the signed update manifest and the pinned verification public key. Users of beta.1 or beta.2 should download and install this release once using the DMG. Subsequent compatible signed releases can use **Install and Restart** from within ChopChop.

The app contains only the public verification key. The private signing key stays in the release signing environment. This update signature is separate from Apple Developer ID signing and notarization: this beta remains **ad-hoc signed and not notarized by Apple**.

### Installation

Requires **Apple Silicon** and **macOS 26.5 or later**. Download the DMG and checksum, verify the download, then open the image and drag ChopChop into Applications:

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.3-macos-arm64.dmg.sha256
```

See the [installation instructions](https://github.com/Conight/ChopChop#install) for the existing macOS installation requirements. Settings, task history, downloaded files, and the separately installed engine are retained.

### Validation and limitations

- The release gate includes Swift unit and migration tests, English/Chinese offscreen layout checks, browser extension tests, isolated real HTTP/RPC and HLS/DASH downloads, updater installation/restart/rollback checks, and Release/DMG verification.
- Validation runs on macOS 27 with Xcode 27. Runtime testing on a separate macOS 26.5 installation, VoiceOver interaction, and public end-to-end upgrades from this release to a future release remain unverified.
- Existing browser-extension setup and direct-media-address limitations remain unchanged. Intel Macs and Safari extensions are not supported.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next is installed separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases); no engine binary or source archive is bundled.
