ChopChop 0.0.1-beta.12

This beta integrates Aria2 Next 3.0.4, improves Thunder link imports, and distinguishes unfinished downloads from completed files on disk.

### Engine and download files

- **Aria2 Next 3.0.4 or later is required.** Installation, saved engine installations, and running RPC connections enforce the same minimum version. Older-engine compatibility branches are removed. Install a supported engine when prompted before resuming downloads.
- **Unfinished file names:** New HTTP, HTTPS, and SFTP downloads use a `.part` suffix in the task's download folder until completion. Existing tasks retain their saved file layout. New filename collisions use browser-style names such as `example (1).zip`.
- **File actions follow the actual payload:** Finder, file verification, and removal use the unfinished file's physical path. Removing a task and its files waits for the HTTP/SFTP task to stop and refreshes its file name before moving the payload to Trash, including when completion races with removal.
- **Upstream fixes:** The new engine baseline includes faster connection recovery after temporary HTTP 503 overload responses and correct handling of zero-length files served with an empty HTTP range response.

### Thunder and browser imports

- **Native Thunder submission:** Validated `thunder://` links are passed intact to the engine. GBK URL bytes, missing or escaped Base64 padding, and trailing-slash variants are supported.
- **Consistent import behavior:** Pasting, dropping, opening Thunder links, and sending them from the browser extension share the updated handling. Wrapped torrent and media sources enter their normal selection flows.
- **ED2K file links:** The browser extension accepts standard pipe-delimited ED2K file links, including those wrapped in Thunder. Browser imports continue to reject embedded URL credentials and local-file URLs.
- **Private diagnostics:** Error messages redact encoded Thunder payloads instead of exposing their contents.

### Known limitation

Aria2 Next 3.0.4 has a final-renaming edge case: if another file appears at the intended final name while a `.part` download is running, publication can fail. ChopChop retains a previously observed partial-file path for cleanup; if that path cannot be established, it refuses file deletion rather than guessing. Avoid placing a new file at an active download's final name. This beta does not repair the upstream engine's recovery state after that failure.

Moving an existing download to another directory is not included.

### Updating and installation

Beta.12 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

The engine is downloaded separately from [official Aria2 Next releases](https://github.com/AnInsomniacy/aria2-next/releases). An installation older than 3.0.4 must be updated before this beta can start it. Settings, task history, downloaded files, and engine recovery data remain outside the app bundle. Restored downloads and BitTorrent seeding stay paused until you resume them.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.12-macos-arm64.dmg.sha256
```

### Validation and development

The release gate runs Swift and migration tests, English/Chinese layout checks, browser-extension tests, real HTTP/RPC and BitTorrent transfers, HLS/DASH downloads, signed updater installation/restart/rollback, and Release/DMG verification. The engine smoke-test baseline is Aria2 Next 3.0.4 and includes native Thunder variants, `.part` pause/restart/resume, parenthesized collision names, and empty range responses. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Hosted tests and network fixtures now require GitHub Actions or a disposable VM. Personal Macs build the fixed-path, Apple Development-signed Dev app, preventing test launches at temporary paths from leaving additional Local Network permission records.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
