ChopChop 0.0.1-beta.17

This beta makes update preparation easier to follow and keeps the download workspace steady when switching sidebar filters.

### Fixes

- **Clear update activity:** Opening the installer, checking the new app, copying it, and closing the installer now have distinct status messages. Stages without measurable progress use a native activity indicator and show elapsed time. Hiding and reopening the window preserves the stage timer. macOS can still take time to close an installer; the window now explains that wait.
- **Stable sidebar filtering:** Empty-state icons occupy a consistent space so switching categories does not shift the title and buttons vertically. Filter changes and removal of hidden selections no longer trigger list movement animations.

### Updating and installation

Beta.17 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

The new update progress display becomes available after installing beta.17; the update to this version is still shown by your currently installed app.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. The engine is downloaded separately.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.17-macos-arm64.dmg.sha256
```

### Validation

The shared CI/release gate includes native keyboard/window regressions, Swift/migration tests, English/Chinese layout, browser-extension checks, real engine/media downloads, signed updater checks, and Release/DMG verification. Updated updater regressions cover every preparation stage, stage timing, cancellation, and the transition from completed download progress to an activity indicator.

Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified. Manual visual review of the new Dev build was unavailable because the window inspection tool timed out.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
