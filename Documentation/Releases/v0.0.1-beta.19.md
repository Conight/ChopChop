ChopChop 0.0.1-beta.19

This beta adds BitTorrent source discovery for Aria2 Next 3.0.8, protects existing files when HTTP downloads cannot resume, and fixes main-window startup after restoring application state.

### Improvements and fixes

- **Find Sources Again:** Active BitTorrent tasks can request fresh sources from trackers, DHT, and local peers without disconnecting existing peers. The action is available in the Downloads menu, task context menu, command search, and torrent settings. Paused and queued tasks stay paused or queued; trackers may enforce a minimum announce interval.
- **Safer metadata retry:** Retrying active Magnet discovery keeps the same task and existing connections. Metadata arriving during the request still opens file selection correctly, without starting file downloads before confirmation.
- **Clearer resume failures:** HTTP downloads that cannot safely resume now explain the possible cause and offer guidance for adding a separate copy. The original engine diagnosis remains available in task logs.
- **Existing-file protection:** Removing a failed download with its files does not delete a preexisting file that the engine refused to resume. Records without confirmed file ownership are also protected. Partial files created separately by ChopChop remain eligible for cleanup.
- **Reliable main-window startup:** Downloads opens even when window restoration does not create the default window. Reopening after Settings, a closed or minimized workspace, or an interrupted sheet no longer depends on a fixed startup delay.

### Engine requirement

**Aria2 Next 3.0.8 or later is required.** Older engine versions are no longer accepted. Update the engine through **Settings → Updates** before updating ChopChop, or use the required engine installation screen after updating.

The engine remains a separate download from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases). Existing download history, files, and engine recovery data are retained.

### Updating and installation

Beta.19 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.19-macos-arm64.dmg.sha256
```

### Validation

The implementation passed full main-branch CI: 454 Swift tests with zero failures and five opt-in skips, 11 native keyboard/window cases passing twice each, Chinese layout checks, browser-extension tests, real Aria2 Next 3.0.8 HTTP/BitTorrent and media downloads, signed updater checks, and Release verification.

The release workflow repeats the shared verification gate before packaging, verifies the mounted DMG, and signs the update manifest. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
