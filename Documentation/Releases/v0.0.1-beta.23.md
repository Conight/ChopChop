ChopChop 0.0.1-beta.23

This beta fixes the menu bar panel in other apps' full-screen Spaces, refines the transfer-rate display, and removes an obstructive focus effect from torrent piece maps.

### Improvements and fixes

- **Menu bar access over full-screen apps:** Revealing the system menu bar while another app is in native full screen and clicking ChopChop now opens the transfer panel. The panel uses the system's native menu bar window scene instead of a manually anchored popover. The reported full-screen scenario was confirmed with the updated Dev app.
- **A more compact, centered menu bar display:** A 16-point icon, lighter typography and aligned download/upload rows improve the balance alongside other menu bar items. Compact three-significant-digit values keep the label narrow, while a reserved width prevents changing rates from shifting neighboring items. Tooltips and VoiceOver retain the full localized rate descriptions.
- **Your display preferences are retained:** Icon only, Speed only, and Icon and speed remain available in Settings → General. Hiding the item preserves the selected mode. The native visibility binding ignores unchanged system writebacks, avoiding unnecessary preference saves and scene updates.
- **Unobstructed torrent piece maps:** Clicking the piece grid no longer draws a large focus effect over the map. Keyboard piece navigation and accessibility remain available.

### Compatibility and installation

**Aria2 Next 3.0.8 or later is required.** Install or update it through **Settings → Updates**. The engine remains a separate download from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).

Existing download history, files, preferences and engine recovery data are retained. Updating ChopChop does not automatically resume paused downloads. The menu bar item's position may reset once when moving to the system-managed container; its visibility and display-mode preferences are preserved. Browser extension **0.0.2** is unchanged and remains included as a separate ZIP with its checksum.

Beta.23 retains the established update verification key. Users on beta.7 or later can update in ChopChop with the **Pre-releases** channel selected. For manual installation, quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Update-package signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.23-macos-arm64.dmg.sha256
shasum -a 256 -c ChopChop-Extension-0.0.2.zip.sha256
```

### Validation and assets

The exact-source verification gate covers Swift tests, English and Simplified Chinese layouts, all 27 UI regressions, persistence and older-store migration, browser-extension and policy checks, real HTTP/BitTorrent/HLS/DASH downloads, updater installation/rollback and hardened Release verification. Focused menu bar regressions check idempotent system visibility writebacks, display-mode persistence, live versus disconnected rates, compact image bounds and background refresh policy. No preview screenshots are exported by these tests.

The release workflow independently rebuilds Distribution, checks the application and mounted DMG, signs the update manifest, and verifies package checksums before publication. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, DMG SHA-256 checksum, signed update manifest, extension ZIP, and extension SHA-256 checksum**.
