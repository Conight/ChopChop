ChopChop 0.0.1-beta.5

This beta introduces a clearer native download list and fixes the quit sequence used by Install and Restart.

### Improvements

- **A simpler download list:** Flat rows replace nested cards and expanding summaries. File icons, names, status, progress, transfer speeds, and actions use consistent spacing and alignment, including in narrow windows.
- **Predictable interactions:** Click once to select, double-click to pause or resume one download, and press Space to open details. Task speed limits, scheduling, and Show in Finder remain available from the contextual menu.
- **Clearer transfer states:** Completed downloads and seeding tasks no longer show a finished progress bar. BitTorrent tasks show upload activity, unknown-size downloads show transferred bytes, and checking or finalizing files no longer display a misleading zero transfer speed.
- **Reliable update shutdown:** Programmatic quit now allows asynchronous session cleanup to finish before the app exits. This fixes updates getting stuck at **Waiting for ChopChop to quit** and also covers quit actions in Engine setup and the menu-bar panel.
- **Additional regression coverage:** Added checks for native list actions, stable layouts, repeated quit requests, and an updater fixture that asks the running app to quit, verifies cleanup, and checks that the replacement stays running.

### Updating

Beta.5 uses the **same update verification key as beta.3 and beta.4**.

**For beta.3 and beta.4, manual installation from the DMG is recommended for this update.** The old app executes the quit step, so the fix in beta.5 cannot repair that step before beta.5 is installed. Quit ChopChop normally before replacing it in Applications. If an update is already stuck waiting for the app to quit, restart your Mac before installing the DMG instead of replacing a running app.

Users of beta.1 or beta.2 should also install this release manually. Existing settings, task history, downloaded files, and Engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

### Installation and validation

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Apple Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.5-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layout checks, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
