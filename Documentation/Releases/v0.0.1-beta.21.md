ChopChop 0.0.1-beta.21

This beta adds observed task activity, temporary bandwidth limits, safer public tracker management, and a more reliable browser handoff with submission receipts.

### Improvements and fixes

- **Task activity and speed history:** Task details now include an observed status timeline, download/upload curves, averages, and peak speeds. History is bounded and persists across app launches. Disconnected intervals and recovered observations are explicitly marked; the app does not invent measurements for time it did not observe.
- **Temporary bandwidth caps:** Apply a 30-minute, one-hour, or open-ended cap from the menu bar, configure its rates in Downloads settings, and clear it at any time. Temporary caps can tighten the current global or scheduled limit without raising an existing limit. Expiration is retained across launches, with visible application errors and pending state.
- **Tracker diagnostics and curation:** BitTorrent settings now retain successful per-source snapshots, preserve manual trackers and exclusions, and select a bounded set with host diversity. Optional connection probes expose recent reachability, latency, and failure cooldowns for the current network route. These are connection measurements, not evidence that an announce or download succeeded. Unsupported proxy configurations skip probing instead of falling back to a direct connection.
- **Private torrent protection:** Automatic public tracker supplements are applied only after the engine explicitly identifies a torrent as public. Private torrents and unresolved metadata are protected. Replacing or clearing a supplement removes only entries ChopChop can positively identify as its own, bound to the torrent's info hash; original and manually configured trackers are preserved.
- **Browser submission receipts:** Extension 0.0.2 checks app protocol support before sending a download. Durable request identities prevent automatic replay of uncertain submissions. The popup can read confirmation state and associated task progress, then reveal those tasks in ChopChop. Interrupted or ambiguous results remain visible for review. Receipt retention is bounded to seven days and is not an unlimited deduplication guarantee.
- **Optional request details:** For one explicitly selected HTTP(S) resource, the extension can request permission to forward matching cookies and request context. Forwarded credentials remain bound to that resource's original origin; editing it to another origin requires clearing those credentials. Credentialed descriptor downloads do not automatically follow Torrent/Metalink payloads. Optional browser access can be revoked in extension settings.
- **Shared submission handling:** Browser, native, and Shortcuts imports use the same application services. Late asynchronous results retain their original import identity, and provisional metadata tasks are not reported as confirmed downloads. New architecture checks and regression coverage exercise these boundaries.

### Browser extension

The app includes extension **0.0.2**, also provided as a separate ZIP and SHA-256 checksum. Extract the ZIP before loading it through Chrome or Edge's extension developer mode. Update and restart ChopChop before using the new extension, then keep Browser Integration enabled and pair it with the app. Existing URL-only imports from the older extension remain supported.

No Chrome Web Store or Edge Add-ons publication is included. The extension uses the local paired bridge, does not automatically take over browser downloads, and does not send browsing or download history to a remote service. Optional cookie and site access requires an explicit action. See the [browser setup guide](https://github.com/Conight/ChopChop/blob/v0.0.1-beta.21/BrowserExtension/README.md) and [privacy details](https://github.com/Conight/ChopChop/blob/v0.0.1-beta.21/Documentation/BrowserPrivacy.md).

### Engine requirement

**Aria2 Next 3.0.8 or later is required.** Install or update it through **Settings → Updates**. The engine remains a separate download from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).

Existing download history, files, and engine recovery data are retained. Updating ChopChop does not automatically resume paused downloads.

### Updating and installation

Beta.21 retains the update verification key used since beta.3. Users on beta.7 or later can update in ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.21-macos-arm64.dmg.sha256
shasum -a 256 -c ChopChop-Extension-0.0.2.zip.sha256
```

### Validation

The release workflow runs the shared verification gate before publication: Swift unit tests, repeated native keyboard/window tests, Chinese layout checks, browser-extension and domain-policy tests, real Aria2 Next HTTP/BitTorrent and media downloads, signed updater checks, and Release verification. It then verifies the mounted DMG, packages the extension, checks asset checksums, and signs the update manifest.

Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, DMG SHA-256 checksum, signed update manifest, extension ZIP, and extension SHA-256 checksum**.
