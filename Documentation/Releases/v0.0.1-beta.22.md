ChopChop 0.0.1-beta.22

This beta adds live download and upload speeds to the menu bar, with three persistent display modes.

### Improvements and fixes

- **Choose your menu bar display:** Open **Settings → General → Menu bar display** and select **Icon only**, **Speed only**, or **Icon and speed**. Existing installations keep Icon only by default. Hiding the menu bar item preserves the selected mode for the next time you show it.
- **Live transfer rates:** Speed modes show download and upload rates in two compact rows, including upload-only seeding. These are ChopChop's transfer rates, not whole-Mac network traffic. Active transfers refresh once per second while speed text is enabled, even with the Downloads window closed. Idle polling and connection-failure backoff retain their existing behavior.
- **Stable, accessible status text:** Localized byte units, monospaced digits and a reserved width keep rate changes from moving neighboring items. Tooltips and VoiceOver expose the full download/upload descriptions. A stopped engine or failed connection shows a dash instead of a stale transfer rate; a connected idle engine shows zero.
- **Reliable import options:** The Advanced Options header is clickable across its full row, retains its native disclosure accessibility semantics, and supports expansion, collapse and reopening while the sheet's main actions remain reachable.
- **More focused regression coverage:** Native layout tests now assert geometry and control values directly instead of exporting preview images. Explicit launch scenarios keep UI fixtures coherent, and every UI regression is included in the ordinary verification gate. The release uses successful verification of the exact source commit before rebuilding the production package.

### Compatibility and installation

**Aria2 Next 3.0.8 or later is required.** Install or update it through **Settings → Updates**. The engine remains a separate download from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).

Existing download history, files, preferences and engine recovery data are retained. Updating ChopChop does not automatically resume paused downloads. Browser extension **0.0.2** is unchanged and remains included as a separate ZIP with its checksum.

Beta.22 retains the established update verification key. Users on beta.7 or later can update in ChopChop with the **Pre-releases** channel selected. For manual installation, quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**. Update-package signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.22-macos-arm64.dmg.sha256
shasum -a 256 -c ChopChop-Extension-0.0.2.zip.sha256
```

### Validation and assets

The exact-source verification gate covers Swift tests, English and Simplified Chinese layouts, all 27 UI regressions, persistence and older-store migration, browser-extension and policy checks, real HTTP/BitTorrent/HLS/DASH downloads, updater installation/rollback and hardened Release verification. Focused menu bar tests exercise all three modes on a native status button, accessibility values, rate/connection changes, preference persistence and background refresh policy without exporting screenshots.

The release workflow independently rebuilds Distribution, checks the application and mounted DMG, signs the update manifest, and verifies package checksums before publication. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, DMG SHA-256 checksum, signed update manifest, extension ZIP, and extension SHA-256 checksum**.
