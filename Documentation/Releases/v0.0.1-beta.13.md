ChopChop 0.0.1-beta.13

This beta adds familiar macOS keyboard commands to the download list.

### Keyboard improvements

- **Command–Delete:** Remove the selected download or multiple selected downloads through the existing removal flow. Confirmation preferences and the choice to keep files or move them to Trash still apply. The shortcut is scoped to the focused task list; text fields retain their normal editing behavior.
- **Command–F:** Focus the download search field directly. Search Downloads is also available in the Edit menu and command search.
- **Command–V:** Paste download links, Torrent files, or Metalink files into the task list to review them through the existing import flow. Pasting into a text field continues to edit that field.
- **Command–A and focus:** Select all visible downloads, including in the filtered queue. Keyboard removal targets that selection, and cancelling its confirmation returns to the list. Download and confirmation sheets keep their own keyboard focus. Arrow-key selection and Space/Escape details controls are retained.

### Updating and installation

Beta.13 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. The engine is downloaded separately; existing installations can update to 3.0.5 through Settings → Updates. This release does not change the engine minimum or add older-engine compatibility branches.

The upstream `.part` final-renaming edge case described in beta.12 is still present in Aria2 Next 3.0.5. ChopChop retains its file-cleanup safeguards. Moving an existing download to another directory is not included.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.13-macos-arm64.dmg.sha256
```

### Validation

The shared CI/release gate now includes four keyboard UI regressions: confirmed and cancelled removal, filtered Select All, search-field text-editing isolation, and list paste followed by editing in the import sheet. It also runs the existing Swift/migration, English/Chinese layout, browser-extension, real engine/media, signed updater, and Release/DMG checks. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
