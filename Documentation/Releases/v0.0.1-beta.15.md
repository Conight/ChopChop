ChopChop 0.0.1-beta.15

This beta makes download commands, window navigation, and task inspection follow familiar macOS behavior.

### Windows and keyboard commands

- **Command-N creates a download:** New Download uses the standard shortcut and returns to the same download workspace. New, Open, and Paste Download commands also work from Settings, About, and other auxiliary windows.
- **Restore the download window:** Use Command-0, Window → Show Downloads, or Show Downloads in the menu bar popover to restore a closed or minimized workspace. Dock reopening finds the download window even when Settings or About is still visible. Closing the workspace continues to respect the background-download preference.
- **Double-click to inspect:** Double-click active, paused, completed, or historical tasks to open their details without changing transfer state. Row buttons and the Downloads menu continue to control pause and resume.
- **Search Settings with Command-F:** Focus the native settings search field, or select an existing query to replace it. Download-list search and normal text-editing shortcuts retain their existing behavior.
- **More consistent imports and menus:** Paste download links or files copied in Finder through the existing import flow. Empty-clipboard feedback appears in the current window and leaves commands usable after dismissal. Finish recording, retry with saved progress, and move to the top of the queue are also available in the Downloads menu.
- **Updated help:** The keyboard reference and English/Simplified Chinese user guide describe the new shortcuts and window behavior.

### Updating and installation

Beta.15 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. The engine is downloaded separately. This release does not change task storage, the engine minimum, or file-removal behavior.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.15-macos-arm64.dmg.sha256
```

### Validation

The shared CI/release gate includes ten native keyboard/window UI regressions, Swift/migration tests, English/Chinese layout, browser-extension checks, real engine/media downloads, signed updater checks, and Release/DMG verification. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
