ChopChop 0.0.1-beta.18

This maintenance beta refreshes the verification tools and tests downloads against Aria2 Next 3.0.6. The app continues to install the latest supported engine through Settings → Updates.

### Maintenance

- Update the browser-extension test runtime from Node.js 24.15.0 to 24.22.0 LTS.
- Update GitHub Actions setup-node from v5 to v7.1.0 and setup-python from v6 to v7.0.0, retaining full commit-SHA pins.
- Update the isolated HTTP/RPC/BitTorrent and media test engine from Aria2 Next 3.0.4 to 3.0.6, with the official Apple Silicon SHA-256 pinned and verified. The engine remains a separate download.

### Updating and installation

Beta.18 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. Updating ChopChop does not automatically replace an installed engine; use Settings → Updates for engine updates.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.18-macos-arm64.dmg.sha256
```

### Validation

Publication follows a successful full main-branch CI run. The release workflow repeats the shared verification gate before packaging and signing: native keyboard/window regressions, Swift/migration tests, English/Chinese layout, browser-extension checks, real engine/media downloads, signed updater checks, and Release/DMG verification.

Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
