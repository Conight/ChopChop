ChopChop 0.0.1-beta.8

This beta improves download-list readability, torrent file selection, and safety when downloaded files are moved or deleted outside ChopChop.

### Downloads and task details

- **Consistent progress columns:** All tasks show an aligned progress bar, including completed downloads and seeders. Long filenames no longer change the bar width, and download speed, upload speed, and ETA have separate space in both wide and narrow windows.
- **Clearer interaction:** Hover over a download row to see its full name and task information. Opening details now gives the panel keyboard focus; clicking the same row's Details button again closes it, matching the Space shortcut.
- **Subtle native progress animation:** Reported forward progress animates briefly through the system progress control. Paused tasks, corrections, completion, and Reduce Motion use the actual value immediately; no extra progress is estimated between engine updates.
- **A more stable Add Download window:** The window opens taller and enforces a usable minimum height. Resizing, choosing torrent files, and returning with Change Source keep the artwork and controls in place.
- **Faster file selection:** Torrent selection now has visible Select All and Deselect All actions, plus shortcuts for videos, images, audio, subtitles, and archives.
- **Cleaner piece inspection:** Piece outlines stay inside their cells. Hover highlights only the piece under the pointer, with no default selection or jump back to a previously clicked piece.

### File removal and BitTorrent safety

- **Remove tasks after external file deletion:** Files already removed in Finder no longer prevent task removal, including batch operations and offline history records. Permission and disk errors still report a failure instead of being silently ignored.
- **Pause affected torrents:** During refresh, ChopChop checks selected, previously completed torrent files for missing paths, unexpected sizes, and read-access problems. Affected active or queued tasks are paused and show recovery instructions. Skipped and unfinished files are not treated as missing downloads.
- **Keep recovery under your control:** The file-safety hold survives restart and blocks single, batch, and scheduled resumes. Restore the files and explicitly recheck downloaded pieces before continuing. To download deleted content again, remove and re-add the task.
- **ChopChop client identity:** BitTorrent advertises `ChopChop/0.0.1-beta.8` with a `ChopChop-` peer-ID prefix. The regular HTTP User-Agent setting remains independent.
- **Clearer continuous-seeding settings:** Switching to continuous seeding explains when an engine restart is required and that existing tasks retain their own sharing policies. Applying runtime settings preserves the currently effective scheduled bandwidth caps.

**Aria2 Next 2.8.6 limitation:** Local-network peers are exempt from the engine's global bandwidth limits. Set a per-task upload limit to cap those connections as well. ChopChop now explains this in the relevant controls.

### Updating and installation

Beta.8 uses the **same update verification key as beta.3 through beta.7**. Users on beta.7 can update through ChopChop's updater. Manual installation from the DMG is recommended for older betas because their updater may stall while waiting for the previous app to quit. Quit ChopChop normally before replacing it in Applications.

Existing settings, task history, downloaded files, and Engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.8-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layouts, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
