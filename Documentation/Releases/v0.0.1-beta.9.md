ChopChop 0.0.1-beta.9

This beta introduces a new native app icon and a simpler menu bar panel.

### Icon and interface

- **A new double-chevron icon:** Equal-width arrows, a slightly lower visual center, and native layers and lighting replace the previous app artwork. The app uses an Icon Composer source, with matching light and dark artwork in the update window.
- **A matching menu bar symbol:** A monochrome vector version of the double chevrons stays clear at menu bar size and follows the system's template rendering.
- **A simpler menu bar panel:** The panel opens directly with download and upload speeds, followed by active tasks and controls. The repeated app title and engine-status heading have been removed.
- **Browser extension icons:** The browser toolbar and extension manager now use the same app identity, with dedicated small-size assets.
- **A quieter engine setup window:** The setup heading uses plain text without an extra decorative icon.

### Updating and installation

Beta.9 uses the **same update verification key as beta.3 through beta.8**. Users on beta.7 or beta.8 can update through ChopChop's updater. Manual installation from the DMG is recommended for older betas because their updater may stall while waiting for the previous app to quit. Quit ChopChop normally before replacing it in Applications.

Existing settings, task history, downloaded files, and engine recovery data are preserved. Restored downloads and BitTorrent seeding remain paused until you resume them.

Requires **Apple Silicon** and **macOS 26.5 or later**. This beta remains **ad-hoc signed and not notarized by Apple**; update signatures do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.9-macos-arm64.dmg.sha256
```

The release gate covers Swift unit and migration tests, English/Chinese offscreen layouts, browser-extension tests, real HTTP/RPC, BitTorrent and media downloads, signed update installation/restart/rollback, and Release/DMG verification. Validation runs on macOS 27 with Xcode 27; a separate macOS 26.5 runtime check remains unverified.

Assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**. Aria2 Next continues to install separately from its [official upstream releases](https://github.com/AnInsomniacy/aria2-next/releases).
