ChopChop 0.0.1-beta.16

This beta fixes the Browser Capture page's background so the window artwork remains visible behind the form.

### Fixes

- Remove the opaque scrolling background on the Browser Capture page while retaining its native grouped sections and controls.

### Updating and installation

Beta.16 retains the update verification key used since beta.3. Users on beta.7 or later can update through ChopChop with the **Pre-releases** channel selected. Manual installation from the DMG is recommended for older betas. Quit ChopChop normally before replacing it in Applications.

Requires **Apple Silicon**, **macOS 26.5 or later**, and **Aria2 Next 3.0.4 or later**. The engine is downloaded separately.

This beta remains **ad-hoc signed and not notarized by Apple**. Signed updates do not replace Developer ID signing or notarization. See the [installation instructions](https://github.com/Conight/ChopChop#install).

```sh
shasum -a 256 -c ChopChop-v0.0.1-beta.16-macos-arm64.dmg.sha256
```

### Validation

The shared CI/release gate includes ten native keyboard/window UI regressions, Swift/migration tests, English/Chinese layout, browser-extension checks, real engine/media downloads, signed updater checks, and Release/DMG verification. Native validation runs on disposable macOS 27 hosts with Xcode 27; a separate macOS 26.5 runtime check remains unverified. The background change has not received a separate manual screenshot review.

Release assets contain the **ChopChop DMG, SHA-256 checksum, and signed update manifest**.
